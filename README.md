# AurevonFilter

فروشگاه اینترنتی فروش اکانت/کانفیگ VPN و پوشاک، با پنل مدیریت کامل.

## امکانات

- ثبت‌نام با نام، **نام کاربری**، شماره موبایل (فقط همان بار اول) و رمز عبور — ورودهای بعدی فقط با **نام کاربری + رمز عبور** انجام می‌شود (شماره موبایل دیگر لازم نیست).
- رابط کاربری کاملا بازطراحی‌شده: تم تیره پریمیوم با ترکیب آبی/بنفش/فیروزه‌ای، افکت شیشه‌ای (Glassmorphism)، عمق و حس سه‌بعدی روی کارت‌ها، پس‌زمینه چندلایه انیمیشنی، نشان «پرفروش‌ترین» (خودکار بر اساس فروش) و «ویژه» (قابل فعال‌سازی از پنل مدیریت روی هر محصول)، و مراحل خرید به‌صورت Stepper.
- نمایش محصولات با **پلن/حجم‌های چندگانه** (مثلا برای VPN: 30 گیگ، 60 گیگ، نامحدود و ... هرکدوم با قیمت جدا و انتخاب زنده روی صفحه محصول)
- پوستر/بنر بزرگ صفحه اصلی، کاملا قابل ویرایش از پنل مدیریت (عنوان، توضیح، متن قیمت، تصویر پس‌زمینه)
- سبد خرید و فرآیند خرید ۳ مرحله‌ای شبیه دیجی‌کالا:
  1. تکمیل اطلاعات گیرنده → ثبت سفارش
  2. صفحه پرداخت: نمایش شماره کارت بزرگ با دکمه «کپی شماره کارت» + دکمه «پرداخت کردم»
  3. صفحه جدید برای آپلود تصویر رسید پرداخت
- جای آماده برای اتصال درگاه آنلاین **cartbecart.ir** در آینده (فایل `utils/gateway.js`)
- پنل مدیریت کامل:
  - داشبورد آماری (تعداد محصولات، سفارش‌ها، فروش کل و ...)
  - افزودن / ویرایش / حذف محصول با پلن‌های قیمتی نامحدود (دکمه «+ افزودن پلن»)
  - مدیریت دسته‌بندی‌ها
  - **تنظیمات**: تغییر شماره کارت، نام صاحب کارت، و محتوای پوستر صفحه اصلی — بدون نیاز به دیپلوی دوباره
  - مشاهده سفارش‌ها، تغییر وضعیت، ثبت **کد پیگیری پستی**، مشاهده رسید پرداخت مشتری
- طراحی تیره، سه‌بعدی و مدرن (کارت‌های محصول با افکت hover سه‌بعدی، دکمه‌های برجسته، کارت پرداخت به شکل کارت بانکی)، راست‌چین (RTL)، فونت وزیرمتن

## اجرا روی سیستم خودتان (تست محلی)

```bash
npm install
cp .env.example .env
# فایل .env رو باز کن و مقادیر دلخواه (خصوصا SESSION_SECRET و ADMIN_PASSWORD) رو عوض کن
npm start
```

سرور روی `http://localhost:3000` بالا میاد. با شماره موبایل و رمزی که در `.env` برای `ADMIN_PHONE` و `ADMIN_PASSWORD` گذاشتی وارد `/admin` شو.

## دیپلوی روی Railway

1. یک ریپازیتوری گیت‌هاب بساز و کل این پوشه رو داخلش push کن (فایل `.env` نباید push بشه، در `.gitignore` هست).
2. وارد [railway.app](https://railway.app) شو و پروژه جدید بساز → **Deploy from GitHub repo** رو انتخاب کن و ریپازیتوری بالا رو وصل کن.
3. Railway به صورت خودکار Node.js رو تشخیص میده و با Nixpacks بیلد می‌کنه (فایل `railway.json` هم کمکی هست).
4. برو به تب **Variables** پروژه در Railway و متغیرهای زیر رو (مطابق فایل `.env.example`) اضافه کن:
   - `SESSION_SECRET`
   - `ADMIN_NAME`, `ADMIN_PHONE`, `ADMIN_PASSWORD`
   - `CARD_NUMBER`, `CARD_HOLDER`, `CARD_BANK`
   - `SHOP_NAME`
   - `DATA_DIR` را برابر `/app/data` بگذار (مرحله بعد توضیح داده میشه)
   - (بعدا که خواستی درگاه رو وصل کنی: `PAYMENT_GATEWAY_ENABLED=true` و اطلاعات cartbecart.ir)
5. **خیلی مهم — پایداری اطلاعات:** فضای فایل روی Railway با هر دیپلوی جدید پاک میشه. برای اینکه دیتابیس و عکس‌های آپلودی (محصولات و رسیدها) از بین نره:
   - در پروژه Railway از بخش **Volumes** یک Volume جدید بساز.
   - مسیر Mount رو `/app/data` بذار (همون مقداری که برای `DATA_DIR` گذاشتی).
   - بعد از این، دیتابیس SQLite و تمام عکس‌های آپلودی داخل این Volume ذخیره و در دیپلوی‌های بعدی هم حفظ می‌شن.
6. دیپلوی رو بزن. بعد از بالا اومدن سرور، وارد `/register` یا `/admin` شو (با شماره و رمزی که در Variables گذاشتی وارد پنل مدیریت شو).

## اتصال درگاه پرداخت آنلاین (cartbecart.ir) در آینده

فعلا فقط روش کارت‌به‌کارت فعاله. وقتی خواستی درگاه آنلاین وصل بشه:

1. مستندات API سایت cartbecart.ir رو بگیر (Merchant ID، API Key، آدرس API درخواست پرداخت و verify).
2. فایل `utils/gateway.js` رو باز کن — توابع نمونه و کامنت‌های راهنما همون‌جا آماده‌ست.
3. یک دکمه/روش پرداخت آنلاین به صفحه `/checkout` و روت `routes/shop.js` اضافه کن که کاربر رو به لینک پرداخت درگاه هدایت کنه.
4. یک روت callback (مثلا `POST /payment/callback`) اضافه کن که بعد از پرداخت موفق، وضعیت سفارش رو به «پرداخت تایید شد» تغییر بده.

## پرداخت آنلاین با بله‌پی (Bale Pay)

بله‌پی از طریق **ربات بله** کار می‌کند: فروشگاه یک فاکتور به چت مشتری در اپلیکیشن بله می‌فرستد، مشتری همان‌جا
پرداخت می‌کند و بله نتیجه را از طریق یک **وبهوک** به سایت اطلاع می‌دهد. همه‌چیز آماده و در پروژه پیاده‌سازی
شده (`utils/baleApi.js`, `utils/balePay.js`, `routes/bale.js`)؛ فقط کافیه اطلاعات ربات رو تنظیم کنی.

### ۱) ساخت ربات و دریافت توکن‌ها

1. در اپلیکیشن بله وارد چت `@BLBot` شو و با دستور `/newbot` یک ربات جدید برای فروشگاه بساز.
2. توکن ربات (Bot Token) که BLBot می‌ده رو در `BALE_BOT_TOKEN` بذار.
3. یوزرنیم ربات (بدون @) رو در `BALE_BOT_USERNAME` بذار.
4. از داخل همون گفتگو با BLBot، فعال‌سازی پرداخت (بله‌پی) رو برای ربات انجام بده تا یک **Provider Token**
   بگیری؛ اون رو در `BALE_PROVIDER_TOKEN` بذار. (این مرحله معمولا نیاز به تایید هویت/تجاری داره؛ اگه دسترسی
   نداشتی، فعلا `BALE_PAY_ENABLED=false` بمونه و همون کارت‌به‌کارت فعال باقی می‌مونه.)

### ۲) تنظیم متغیرهای محیطی

در `.env` (یا Variables روی Railway) این‌ها رو پر کن:

```
BASE_URL=https://<دامنه سایتت>
BALE_PAY_ENABLED=true
BALE_BOT_TOKEN=...
BALE_PROVIDER_TOKEN=...
BALE_BOT_USERNAME=...
BALE_WEBHOOK_SECRET=<یک رشته تصادفی طولانی>
```

برای ساخت `BALE_WEBHOOK_SECRET` می‌تونی این دستور رو اجرا کنی:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### ۳) ثبت وبهوک

بعد از بالا اومدن سرور با متغیرهای بالا، وارد پنل مدیریت شو → تب **🅱️ بله‌پی** (`/admin/bale`) → دکمه
«ثبت / به‌روزرسانی وبهوک» رو بزن. سایت خودش آدرس `${BASE_URL}/webhook/bale/${BALE_WEBHOOK_SECRET}` رو نزد
بله ثبت می‌کنه.

### ۴) نحوه کار برای مشتری

1. مشتری روی «پرداخت با بله‌پی» در صفحه پرداخت سفارش کلیک می‌کنه.
2. بار اول ازش خواسته می‌شه حساب فروشگاهیش رو یک‌بار به چت بله وصل کنه (لینک `/bale/connect` و دستور
   `/start <کد>` داخل ربات) — همون کاری که ربات‌های تلگرامی هم برای شروع گفتگو لازم دارن.
3. بعد از اتصال، با هر بار زدن دکمه، فاکتور مستقیم داخل چت بله ارسال می‌شه.
4. بعد از پرداخت موفق، بله رویداد `successful_payment` رو به وبهوک سایت می‌فرسته و سفارش خودکار به وضعیت
   «پرداخت تایید شد» تغییر می‌کنه — نیازی به آپلود رسید یا تایید دستی ادمین نیست.

اگه `BALE_PAY_ENABLED=false` باشه یا اطلاعات ربات کامل نباشه، دکمه بله‌پی اصلا نمایش داده نمی‌شه و فقط
کارت‌به‌کارت فعاله.

## ساختار پروژه

```
server.js              نقطه ورود اصلی
config/db.js           اتصال و ساخت جداول دیتابیس (SQLite)
config/seed.js         ساخت ادمین اولیه و داده‌های نمونه
middleware/auth.js      میدلورهای ورود/دسترسی ادمین
routes/auth.js          ثبت‌نام، ورود، خروج
routes/shop.js          فروشگاه، سبد خرید، تسویه حساب، سفارش‌های کاربر
routes/admin.js         پنل مدیریت (محصولات، دسته‌بندی، سفارش‌ها)
utils/upload.js         تنظیمات آپلود تصویر (multer)
utils/gateway.js        محل آماده برای اتصال درگاه پرداخت آینده
views/                  قالب‌های EJS (فروشگاه + پنل مدیریت)
public/                 فایل‌های CSS و JS
data/                   دیتابیس SQLite و عکس‌های آپلودی (روی Railway باید Volume باشه)
```

## نکات امنیتی قبل از فروش واقعی

- حتما `SESSION_SECRET` و `ADMIN_PASSWORD` رو به مقادیر قوی و تصادفی تغییر بده.
- روی Railway، دامنه پیش‌فرض HTTPS داره؛ اگه دامنه اختصاصی وصل کردی هم گواهی SSL خودکار فعال میشه.
- به‌صورت دوره‌ای از Volume/دیتابیس بک‌آپ بگیر.
